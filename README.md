# Go Ratings & Stats

腾讯围棋协会内部对局与等级分看板。

页面以只读查询为主，采用无侧栏单栏布局；排行榜默认使用适合手机宽度的简洁视图。对局数据直接在 GitHub 的 `data.csv` 中维护。

## 当前等级分规则（v2）

所有棋手仍从 1500 分开始。每一局双方分别按自己的赛前状态计算：

`本局变化 = 个人 K 值 × 赛事权重 ×（实际结果 − 预期结果）`

个人 K 值按“有效对局数”变化：

| 赛前有效对局数 | K 值 | 页面状态 | 含义 |
| --- | ---: | --- | --- |
| 少于 10 | 48 | 暂定 | 样本很少，分数会较快校准 |
| 10 至不足 30 | 40 | 校准中 | 已有一定参考，仍可能明显变化 |
| 30 及以上 | 28 | 稳定 | 样本较充分，降低单局波动 |

赛事权重：

| 赛事 | 权重 | 每下一局增加的有效对局数 |
| --- | ---: | ---: |
| 腾讯围棋大赛现场赛 | 1.0 | 1.0 |
| 腾讯围棋大赛预选赛 | 0.8 | 0.8 |
| 捉早杯、捉早贺岁杯、菜鸡杯 | 0.5 | 0.5 |
| 未识别赛事 | 0 | 0 |

第 10 届个人赛数据中的“个人赛 A 组”按预选赛处理。弃权和轮空没有录入数据，因此计算程序不需要额外剔除。

## v1 保留方式

页面侧边栏可以切换到“v1 旧规则（对照）”。v1 对所有对局等权，双方固定使用 K=32。

迁移当天的不可变榜单保存在 `snapshots/rating_v1_2026-09-08.csv`，用于以后解释规则调整前后的差异。
